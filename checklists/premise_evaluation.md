# Premise Evaluation Checklist

Run before any outline. Score each item 0-2. A premise below 12/16 goes back for revision; do not "fix it while drafting".

## 1. One-sentence statement

Write: "A [protagonist] who [concrete want] must [act] against [specific obstacle], and success will cost [specific cost]."
- [ ] Names a person, not a role ("a courier", not "humanity").
- [ ] The want is concrete and external.
- [ ] The obstacle is specific and active.
- [ ] The cost is named now, not discovered later.

Score 0-2.

## 2. Engine test

List ten conflicts the premise generates without adding new elements.

1. ______  2. ______  3. ______  4. ______  5. ______
6. ______  7. ______  8. ______  9. ______  10. ______

- [ ] At least five are usable as scenes, not just situations.
- [ ] At least three can be caused by prior choices rather than imported.

Score 0-2.

## 3. Specificity test

- [ ] Name the one rule, relationship, or contradiction that makes this story not generic: ______
- [ ] If the answer is a theme, mood, or setting, fail.

Score 0-2.

## 4. Cost test

- [ ] What does the premise take from the protagonist in act one? ______
- [ ] A premise that only grants (power, status, prophecy, chosenness) fails.

Score 0-2.

## 5. Dramatic question

- [ ] Phrase it: ______
- [ ] It cannot be answered before the final act.
- [ ] It is not answerable with "yes" or "no" alone (a yes/no question produces a thin ending).

Score 0-2.

## 6. Variation test

- [ ] Three genuinely different plausible resolutions:
  A ______  B ______  C ______
- [ ] Each would mean something different about the protagonist.
- [ ] If only one exists, the plot is a corridor.

Score 0-2.

## 7. Convergence test

- [ ] List the subplots the core conflict pulls in: ______
- [ ] Each can be closed by the same climax.
- [ ] Any subplot that cannot converge is cut now.

Score 0-2.

## 8. Furniture test

List familiar genre elements and the transformation applied:

| Element | Transformation that makes it specific |
| --- | --- |
| | |
| | |
| | |

- [ ] Transformation, not avoidance: familiar elements used precisely beat novelties used vaguely.
- [ ] If an element has no transformation, it will read as borrowed.

Score 0-2.

## Verdict

Total: ___ /16.

- 13-16: proceed to architecture.
- 9-12: revise the two weakest items; re-run.
- 0-8: the premise is a setting. Return to the character's want and the world's cost.

## Notes

Record failed tests and the reason. Do not quietly upgrade a weak premise. Note any assumption made because the user did not specify (genre expectations, length, audience).
