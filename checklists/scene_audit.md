# Scene Audit

Use per scene, before drafting or when diagnosing. A scene that fails items 1-6 is not a scene; it is a report. Fix it or summarise it inside another unit.

## A. Scene card

- POV:
- What the POV knows at entry:
- Goal in this scene (concrete, immediate):
- Obstacle (person / rule / information / time / self):
- Tactic 1:
- Tactic 2 (escalation):
- Turn (what changes the terms):
- Decision (what the POV chooses):
- Cost of the decision:
- Consequence carried into the next scene:
- Change statement: "At entry, ______. At exit, ______."

## B. Pass/fail checks

1. **Change.** Is the change statement different at both ends? If "nothing", fail.
2. **Agency.** Did the POV cause the turn? If another character or coincidence caused it, is the POV's response itself a consequential choice?
3. **Stakes.** What can be lost in this scene, and is it visible to the reader?
4. **Reconstructable choice.** Could the reader explain the decision from motive and information available at that moment? If not, plant the missing information earlier.
5. **New information.** Does the reader learn something they did not know, or see something they knew in a new light?
6. **Irreversibility.** Does something become harder or impossible to undo?

Any "no" in 1-3 is a structural failure; any "no" in 4-6 is a local weakness.

## C. Dramatisation threshold

Dramatise if the event:
- [ ] changes a relationship, stake, or knowledge irreversibly;
- [ ] is a first or last time;
- [ ] must be felt for a later choice to be credible.

Otherwise summarise it inside another scene. Never summarise the climax.

## D. Dialogue audit

- [ ] Each speaker wants something from the other in this exchange.
- [ ] At least one speaker resists or evades.
- [ ] No character explains what both parties already know.
- [ ] Power is negotiated through control of the frame, not volume.
- [ ] The subtext can be inferred but is never stated.
- [ ] Voices differ in syntax and vocabulary, not only in tag.

## E. Prose audit

- [ ] One precise, character-relevant detail per descriptive paragraph.
- [ ] Sentence length varies at the turn.
- [ ] Emotion is carried by behaviour or consequence before any interior label.
- [ ] No sentence explains the sentence before it.
- [ ] No repeated information from an earlier scene unless the repetition changes meaning.

## F. Repair ladder

Fix at the lowest level that explains the symptom:

1. Line problem -> rewrite the sentence.
2. Scene problem -> change the goal, obstacle, or decision.
3. Causality problem -> plant the cause in an earlier scene.
4. Chapter problem -> reorder or merge scenes.
5. Arc problem -> change what the arc is about; do not patch scenes.

## G. Fix specification

If the scene fails, write the fix in this form before touching prose:

- Cause to plant: ______
- Where it goes (earlier scene/beat): ______
- What changes in this scene as a result: ______
- Cost or exposure this creates: ______
- One mechanism only. Alternatives go in a separate "Options" line.

A fix that only changes a number, a name, or an adjective is an adjustment; say so.

Even when the user says "do not rewrite", provide this specification. "Do not rewrite" forbids replacement prose, not repair directions.

## H. One-line verdict

State: "This scene works because ______" or "This scene fails because ______, and the minimal fix is ______."
