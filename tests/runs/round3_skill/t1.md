# Diagnosis — Wren synopsis (DIAGNOSE; no rewrite)

**F1. No protagonist goal (5).** Wren never wants anything; she enters the palace because a map appears. Every later beat is done to her, so agency reads as "the plot". *Fix:* plant a concrete want before the map (a delivery she must finish inside the walls), make the map serve it; infiltration costs her courier neutrality.

**F2. Convenient arrival, twice (4).** The map's sender is never named or motivated, and the army arrives "because the army had been waiting for a signal" — a cause created in the clause that needs it. An army idle through the siege contradicts the siege. *Fix:* decide who sent the map and what the signal was; plant both in act one; state where that army has been.

**F3. Oris defects for a sandwich (4).** A shared meal buys treason. *Fix:* give Oris a prior stake that already endangers him, so the food is the last nudge, not the cause.

**F4. Retroactive rule (4).** The silver allergy debuts in the paragraph that uses it; the inkwell is unplanted too. *Fix:* voice the allergy in the guard scene; put the silver inkwell on the treaty table when Wren enters.

**F5. Redundant climax (3).** Armed men surround the palace, so the treaty is void already and the inkwell decides nothing; the signing needs a reason to survive the army. *Fix:* make the army the chancellor's, arriving to enforce the surrender, so only stopping the signature saves the city.
